End-to-End Cognitive Tracking System

During my research at BMCC, I engineered the system architecture and interaction logic for a NAO humanoid robot designed to assist dementia patients.


  • System Architecture: Architected a two-way pipeline connecting the NAO robot's voice input/output to a centralized SQL Database, allowing authorized parties (doctors/caregivers) to securely monitor patient data.
  • Interaction Flow: Programmed state-driven decision trees to power a dynamic memory game that tracks cognitive decline based on real-time patient responses.

WakeUp: Native Android Alarm Application

Engineered a modern, reactive Android application from scratch using Kotlin and Jetpack Compose.


  • Background Services: Integrated Android's AlarmManager API for exact time execution, triggering a custom BroadcastReceiver and foreground Service to bypass background execution limits.
  • Reactive Architecture: Managed asynchronous data streams and UI states using Kotlin Coroutines, StateFlow, and DataStore for persistent, thread-safe user preferences.
  • Custom Interactions: Engineered a custom Jetpack Compose slider that requires users to drag a physical UI element to 90% completion to silence the MediaPlayer audio stream.
Kotlin Jetpack Compose Coroutines / StateFlow Android DataStore
